# 🖼️ Gallery (v1.0.1)

A modern, fast, and private offline Android gallery and file manager built with Material 3, AndroidX Media3 (ExoPlayer), and CameraX.

## 📖 Comprehensive Documentation
👉 For complete feature breakdown and user instructions, see **[APP_FUNCTIONALITY.md](file:///d:/_test/gallery/APP_FUNCTIONALITY.md)**.

## ✨ Highlights
- **4 Main Tabs:** All Media, Folders (Albums), Device File Explorer, Private Vault.
- **Collage Maker:** Multi-layout grid photo collage maker with custom borders, background colors, and tap-to-swap.
- **Photo Editor:** Crop presets (1:1, 4:3, 16:9, Free), 90° rotation, wallpaper setter, EXIF inspector.
- **Video Player:** Full-screen Media3 ExoPlayer with speed control (0.5x to 2.0x), aspect ratio toggle, and Picture-in-Picture (PiP).
- **Secure Vault:** 4-digit PIN-protected hidden storage (`.vault`) isolated from external apps.
- **Storage Analyzer:** Storage category breakdown, Duplicate Finder, Large Files cleaner, Empty Folder cleanup.
- **Distribution:** Download APK directly to public Downloads folder, Share APK via FileProvider, and Developer Feedback.
